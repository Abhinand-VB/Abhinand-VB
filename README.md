## About Me

I'm **Abhinand Vijayakumar Binsu** — I take ideas from concept to working prototype, across production mobile apps, distributed systems, and applied AI.

- 🎓 **M.S. Software Engineering** — San Jose State University, San Jose, CA
- 🏢 **3+ years** building enterprise airline & travel software at **IBS Software** (Solution Engineer → Senior Solution Engineer)
- 📱 Shipped customer-facing apps: [Star Flyer Booking App](https://play.google.com/store/apps/details?id=jp.starflyer.bookingapp&hl=en_US) (**50K+ downloads**) and [iFlyCorporate Etihad](https://apps.apple.com/gh/app/iflycorporate-etihad/id6749933493)
- 🛰️ **Former Project Trainee @ ISRO** — closed-loop FOC control systems & SPICE circuit simulation
- 🔭 Currently building distributed AI infrastructure — leader election, Kafka task routing, failover, observability
- 💼 **Open to software engineering roles**
